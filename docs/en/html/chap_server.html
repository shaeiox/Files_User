Chapter 3 — server.js: The HTTP Transport Layer

Landing chapter for the server.js documentation: routing, headers, security gates, streaming, and the funnel that turns every service error into JSON.

The project's only network listener. It contains zero filesystem logic: each of its six API routes delegates to one function of lib/files-service.js, then handles purely transport concerns — JSON encoding, CORS, MIME, Content-Disposition, streamed bytes, and the security blocklist for /.env, /lib/ and /node_modules/.

🎯 Why read this chapter
Every cross-origin request, every download and every error response the browser ever sees is shaped here. The startup banner and /api/health also report FILES_ROOT state from here, which makes this file the operator's first debugging stop.
