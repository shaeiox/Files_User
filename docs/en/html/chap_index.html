Chapter 1 — index.html: The SPA Shell

Landing chapter for the index.html documentation: what the shell does, what its deep dive covers, and where to go next.

Every visit to the portal starts here. server.js answers /, /index.html and any unknown HTML-ish route with this one file (serveSPA()), and the browser never performs a full navigation away from it again — all "pages" are views mounted into its <main id="app"> container.

🎯 Why read this chapter
The shell owns the two decisions that happen before first paint: which theme and which performance tier apply (preventing flash-of-unstyled content), and in which order fonts, CSS and the deferred scripts load. Everything else in the frontend depends on those choices.
