Chapter 4 — lib/files-service.js: The Filesystem Domain Layer

Landing chapter for the files-service.js documentation: FILES_ROOT ownership, the path-safety wall, and everything that reads the download tree.

The bottom of the back-end and the only file that touches the downloads tree. It resolves and validates FILES_ROOT, converts every client-supplied path into a provably-inside-root absolute path, walks the tree for categories, listings, search and releases, and returns the metadata bundle that server.js streams. It never sees HTTP objects.

🎯 Why read this chapter
This is where the portal's security and its data contracts live: the 403 PATH_TRAVERSAL wall protects every byte the server ships, and the shapes returned by listCategories/listPath/searchEntries/ listLatestReleases are consumed field-by-field by the frontend service layer. The chapter also documents the full error-code table the other chapters rely on.
